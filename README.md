# ShortcutBook (바로가기 목록)

프로그램 바로가기를 **이름·설명·매뉴얼과 함께** 모아 보는 프로그램입니다.
오래된 바로가기 아이콘만 봐서는 무슨 프로그램인지 기억나지 않는 문제를 풀기 위해, 아이콘 옆에 이름과 설명, 매뉴얼·웹 주소·메모를 같이 보여 줍니다.

- WPF / .NET 10 (`net10.0-windows10.0.19041.0`, Fluent 테마 사용), 빌드 번호는 `.build_number` (실행 파일 버전 `1.0.<빌드번호>`)
- 제작자: 이스트 / 지원 연락: redwoodmane@gmail.com (도움말 `?` 창에 표시)

## 목록 파일과 탐색기 연동

- 목록 하나는 확장자 `.sbook` 파일(JSON) 하나입니다. 더블클릭하면 이 프로그램이 열립니다.
- 처음 실행하면 현재 사용자 영역(`HKCU\Software\Classes`)에 등록됩니다 (관리자 권한 불필요).
  - 탐색기 빈 곳 우클릭 → **새로 만들기 → 새 바로가기 목록**: 새 폴더를 만들 때처럼 빈 파일이 생기고 이름을 바로 지정합니다. (`ShellNew\NullFile`)
  - 0바이트 파일도 빈 목록으로 읽습니다.
- 설정 창의 체크 상자로 등록/해제할 수 있습니다. 실행 파일 위치가 바뀌면 다음 실행 때 자동으로 다시 등록됩니다.
- 프로그램을 직접 실행(목록 지정 없음)하면 시작 창(최근 목록 · 새로 만들기 · 열기)이 뜹니다.

## 화면 구성

| 위치 | 기능 |
|---|---|
| 상단 | 검색 · `+` 추가 · 설정 · 정렬 선택 · `?` 도움말 |
| 한 줄 | 끌기 손잡이 · 아이콘 · 이름 | 설명(이름 오른쪽, 빌드 #11부터. 이전은 이름 아래) · (매뉴얼/웹 주소/메모 아이콘) · 수정 |

- 줄 더블클릭 = 실행. 우클릭 = 실행 / 대상 위치 열기 / 수정 / 삭제.
- 추가: `+` 를 누르거나 바로가기(.lnk)·실행 파일·폴더·`.url`·웹 주소를 창(또는 `+`)에 끌어다 놓으면 팝업이 뜹니다. `.lnk` 는 대상·인수·시작 위치·창 크기·아이콘·설명을 읽어 옵니다.
- 항목 설정: 대상(파일·폴더·웹 주소·다른 `.sbook` 목록) · 인수(`a.exe -fullscreen`) · 시작 위치 · 실행할 앱(대상을 이 앱으로 열기) · 창 크기 · 관리자 권한 · 아이콘 직접 지정 · 매뉴얼 파일 · 웹 주소 · 메모.
- 정렬: 임의 정렬(손잡이를 끌어 순서 변경, 검색 중에는 비활성) / 이름순 / 이름 거꾸로. 정렬 방식은 목록 파일마다 저장됩니다.
- 키보드: Enter = 선택 항목 실행 (선택이 없으면 실행 안 함), 수정 단축키(기본 F2) = 선택 항목 수정 창, Backspace·왼쪽 방향키·마우스 4번 = 이전 목록, 오른쪽 방향키·마우스 5번 = 앞으로.
- 여러 파일을 한꺼번에 끌어다 놓으면 팝업 없이 이름 그대로 일괄 추가됩니다 (하나만 놓으면 세부 설정 팝업).
- 설정: 테마(시스템·라이트·다크), 이름 칸 너비(설명은 이름 칸 바로 오른쪽에 왼쪽 정렬), 목록 크기(작게·중간·크게·아주 크게), 같은 경로·주소 등록 방식(추가 등록[기본] / 등록 제외 / 새로 덮어쓰기), 다른 목록 열기 방식(현재 창 대체[기본] / 새 창), 수정 단축키, 언어, 탐색기 연동, 버전(맨 아래).

## 새로 만들기 메뉴 (2종)

- **새 바로가기 목록**: `.sbook` 파일을 그 자리에 바로 만들고 이름 바꾸기 상태가 됩니다.
- **새 바로가기 목록 바로가기**: 이름을 묻는 창이 뜨고, 목록 파일은 **프로그램 폴더의 `Lists`** (실행 파일 옆)에 만들고, 우클릭한 자리에는 그 목록을 여는 `.lnk` 를 만듭니다. `.lnk` 는 탐색기 속성 > 아이콘 변경으로 아이콘을 바꿀 수 있습니다. 설정 창에서 `Lists` 폴더를 바로 열 수 있습니다. (`bin` 을 통째로 지우면 `Lists` 도 지워지니 주의)
- 일반 파일(.sbook)은 파일 하나만의 아이콘을 탐색기에서 바꿀 수 없어서(형식 전체 아이콘만 있음) 이 방식을 둡니다.

## 언어

`lang\*.json` (실행 파일 옆). `{"_name": "표시 이름", "키": "문장"}` 형식이며, 파일을 추가하면 설정의 언어 목록에 나타납니다. 기준 언어는 `ko.json` 이고 번역에 빠진 키는 한국어로 보입니다. 현재 `ko`, `en`.

## 파일

- 설정·로그: `%AppData%\ShortcutBook\<main|edit|settings|help|start|memo|message>.json`, `log.txt` (환경 변수 `SHORTCUTBOOK_DATA_DIR` 로 폴더 변경 가능)
- 목록 파일 형식 예:

```json
{ "Version": 1, "Sort": "Custom",
  "Items": [ { "Id": "…", "Name": "메모장", "Description": "텍스트 편집기",
               "Target": "C:/Windows/System32/notepad.exe", "Arguments": "",
               "ManualPath": "", "WebUrl": "", "Memo": "" } ] }
```

## 개발용 옵션 (시험용)

| 옵션 | 동작 |
|---|---|
| `--exit` | 실행 중인 인스턴스를 종료 |
| `--new-link <폴더 또는 경로> [--name 이름]` | 탐색기 "새로 만들기 > 바로가기 목록 바로가기"가 호출하는 동작 (이름 창, 프로그램 폴더 Lists 에 목록 파일, 그 자리에 .lnk). `--name` 을 주면 이름 창을 건너뜀(시험용) |
| `--register` | 탐색기 연결(.sbook)을 이 실행 파일로 갱신하고 종료 (빌드 후 자동 실행됨, 설정에서 연동을 끈 경우 건드리지 않음) |
| `--render <main|edit|settings|help|start|memo|message>\|edit\|settings\|help\|start\|memo> <출력.png> [목록.sbook 또는 edit 의 대상 파일]` | 창 본문을 그림 파일로 저장하고 종료 (제목 표시줄 포함 창 전체는 `출력.png.frame.png` 로 함께 저장). 입력 장치 없이 화면 확인용, 탐색기 등록은 건드리지 않음 |

단일 인스턴스입니다. 이미 실행 중일 때 다른 목록을 열면 기존 프로세스에 새 창으로 열립니다 (같은 목록이면 그 창을 앞으로 가져옴).
